4. The FPGA configuration data in the firmware image (not GPL source)
---------------------------------------------------------------------

  The firmware image holds one copy of the FPGA configuration bitstream
  (Gowin GW1N-2 family, 115,638 bytes) that the instrument needs to measure.
  This data was extracted from the FNIRSI stock firmware V1.2.0
  (firmware/src/drivers/fpga_cal_table.h). It is binary data from FNIRSI, not
  source code of this project, and the GPL-3.0 does not apply to it. We have no
  source for it. The upstream OpenScope-2C53T project ships the same data in
  its own release images.

  The FNIRSI stock firmware itself is NOT in this package. To go back to the
  stock firmware you need your own copy of the FNIRSI file.
